# My Site

A simple, plain PHP website with shared header/footer includes.

## Pages

- `index.php` - Home
- `about.php` - About
- `services.php` - Services
- `contact.php` - Contact form with server-side validation

## Structure

```
includes/   Shared header, footer, and site config
assets/css/ Stylesheet
```

## Running locally

```
php -S localhost:8000
```

Then open http://localhost:8000 in your browser.
